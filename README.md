# Kurt's Kool Randomizer PWA

A progressive web app for generating random combinations of Kurt's cool picks.

## Features
- Randomize selections from a curated list
- Fast, installable PWA experience
- Works offline after first load
- Simple, mobile-friendly interface

## Getting Started
1. Open the app in a browser.
2. Install it as a PWA if desired.
3. Use the randomizer to generate a selection.

## Project Status
This project is a lightweight personal app for quick randomization.
